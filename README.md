# Система заявок

Веб-приложение для создания и выполнения заявок с ролевой моделью доступа:
подразделения, руководители работ, исполнители, отчёты для собственника.

## Возможности

| Роль | Что делает |
|------|-----------|
| **Администратор системы** | Создаёт, корректирует, отключает и восстанавливает учётные записи, назначает роли и подразделения, сбрасывает пароли, ведёт список подразделений |
| **Собственник** | Видит все подразделения и все заявки, формирует отчёты за период (сводка по подразделениям, среднее время выполнения, экспорт в CSV) |
| **Администратор подразделения** | Создаёт заявки руководителям работ своего подразделения, видит только заявки своего подразделения, может отменить новую заявку |
| **Руководитель работ** | Принимает заявку в работу и назначает исполнителя, может отклонить заявку (с причиной), сменить исполнителя, вернуть работу на доработку, подтвердить и закрыть выполненную заявку |
| **Исполнитель** | Видит только назначенные ему работы, отмечает их выполнение |

## Жизненный цикл заявки

```
Новая ──► В работе ──► Выполнена ──► Закрыта
  │           ▲            │
  │           └────────────┘  (возврат на доработку)
  ├──► Отклонена (руководителем, с причиной)
  └──► Отменена  (администратором подразделения)
```

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm start
```

Приложение будет доступно на <http://localhost:3000> (порт меняется переменной `PORT`).

При первом запуске автоматически создаётся администратор системы:

- логин: `admin`
- пароль: `admin123` — **обязательно смените после первого входа**.

База данных (SQLite) создаётся автоматически в каталоге `data/`
(меняется переменной `DATA_DIR`).

## Демо-данные

Для демонстрации можно загрузить тестовые подразделения, пользователей и заявки:

```bash
npm run seed:demo
```

Будут созданы учётные записи (логин / пароль):

| Логин | Пароль | Роль |
|-------|--------|------|
| `admin` | `admin123` | Администратор системы |
| `owner` | `owner123` | Собственник |
| `it.admin` | `demo123` | Администратор ИТ-отдела |
| `it.manager` | `demo123` | Руководитель работ (ИТ-отдел) |
| `it.exec1`, `it.exec2` | `demo123` | Исполнители (ИТ-отдел) |
| `hoz.admin` | `demo123` | Администратор хозотдела |
| `hoz.manager` | `demo123` | Руководитель работ (хозотдел) |
| `hoz.exec1` | `demo123` | Исполнитель (хозотдел) |

## Порядок работы

1. Администратор системы создаёт подразделения и учётные записи
   (каждому администратору подразделения, руководителю и исполнителю указывается подразделение).
2. Администратор подразделения создаёт заявку и адресует её руководителю работ.
3. Руководитель принимает заявку в работу и назначает исполнителя
   (или отклоняет с указанием причины).
4. Исполнитель выполняет работу и отмечает её выполненной.
5. Руководитель подтверждает выполнение и закрывает заявку
   (или возвращает на доработку).
6. Собственник просматривает все заявки и формирует отчёты за период.

## Технологии

- **Бэкенд**: Node.js, Express 5, SQLite (better-sqlite3)
- **Аутентификация**: сессии в БД, cookie `httpOnly`, пароли — scrypt
- **Фронтенд**: HTML/CSS/JavaScript без фреймворков (SPA)
